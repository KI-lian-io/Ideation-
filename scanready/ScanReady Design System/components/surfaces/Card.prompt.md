The default content container — flat, 12px radius, warm hairline, no shadow.

```jsx
<Card>
  <CardTitle>Always in sync</CardTitle>
  <p>Your docs update from the same source as your code.</p>
</Card>
<Card variant="feature">…</Card>          {/* paper, borderless */}
<Card variant="testimonial">…</Card>      {/* the one loud terracotta surface */}
```

Never put a drop shadow on a `base` card — flat with hairline is the brand.
