The signature brand label — mono, taupe, uppercase, 0.18em tracked. Sits above a headline.

```jsx
<Eyebrow>Platform</Eyebrow>
<Eyebrow color="var(--on-dark-muted)">What's new</Eyebrow>  {/* on dark bands */}
```

1–3 words, categorical. Never use it for body text or a CTA, and never set it in a non-mono face.
