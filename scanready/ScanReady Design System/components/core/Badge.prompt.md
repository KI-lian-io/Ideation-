Small status / label chip.

```jsx
<Badge tone="discount">Save 20%</Badge>
<Badge tone="required">Required</Badge>
<Badge tone="type">string</Badge>
<Badge tone="tag">Beta</Badge>
```

Tones: `discount` (mint pill), `required` (error mono), `type` (paper mono, for API signatures), `tag` (blue), `warn`, `success`, `neutral`.
