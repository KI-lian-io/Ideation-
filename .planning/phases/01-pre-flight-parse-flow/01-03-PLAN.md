## Phase Goal

**As a** an expat job-seeker, **I want to** paste my US/UK résumé and get an editable, norm-correct German Lebenslauf with bilingual "what changed & why" notes, **so that** I can submit a CV a German recruiter takes seriously in the 8-second scan.

(Plan 03 delivers the "editable, norm-correct German Lebenslauf" and "copy" parts of that story; categorized skill chips, the language dropdown, and the norm-gap panel arrive in Plan 04.)

<threat_model>
ASVS level: L1. Block on: high severity. This plan is entirely client-side editing of in-memory state plus a clipboard write; no new server surface, no persistence.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| parse response / user edits -> React render | Model- and user-supplied text is rendered into editable fields |
| edited state -> clipboard | Plain-text serialization leaves the app only to the user's own clipboard |
