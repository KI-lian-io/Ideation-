## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> `/api/parse` | Untrusted pasted CV text crosses into the server route and on to the model prompt |
| `/api/parse` -> Anthropic API | Server-held `ANTHROPIC_API_KEY` must never cross back to the client bundle |
| parse response -> React render | Model-produced text is rendered into the page |
