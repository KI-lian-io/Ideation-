## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → /api/cover-letter | Untrusted user input (job posting + 5 free-text answers + cvText snapshot) crosses from the browser to the Node route, then to the Claude API. |
| Claude API → browser DOM | AI-generated letter text streams back and is rendered into the DOM. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering (XSS) | Streamed `letterText` render in `CoverLetterStreamingView` | mitigate | Render streamed text as a text node inside `<pre>{letterText}</pre>` — never `dangerouslySetInnerHTML`. React default escaping preserved. Verified by negative grep in Task 3. |
| T-02-02 | Tampering (prompt injection) | Job posting + answers sent to `COVER_LETTER_SYSTEM` | mitigate | The GROUNDING / anti-fabrication directives in `COVER_LETTER_SYSTEM` are the mitigation and stay untouched — the D-09 edit only removes the bracket review-note directive (Task 1 acceptance criterion asserts grounding block unchanged). |
| T-02-03 | Information disclosure | `resumeText`, `lebenslauf`, `jobPosting`, `answers`, `letterText` in client memory | accept | All live in React component memory only; `RESET` clears them; no `localStorage`/`sessionStorage`/server persistence. Consistent with the zero-retention guarantee. Low risk — no PII leaves the device except to the user's own API call. |
| T-02-04 | Information disclosure | `ANTHROPIC_API_KEY` | mitigate | Key stays server-side in the existing route via `process.env`; no client-side reference is introduced in this plan. |
| T-02-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages installed in this phase (RESEARCH "Package Legitimacy Audit: zero vetting required"). `.txt` download uses browser-native Blob. No legitimacy checkpoint needed. |

Severity note: only `high`-severity threats block (config `security_block_on: high`). T-02-01 and T-02-02/04 mitigations are in scope and verified; no high-severity unmitigated threat remains.
