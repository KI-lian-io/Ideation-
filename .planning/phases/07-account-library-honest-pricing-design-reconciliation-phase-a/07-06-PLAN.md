## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated client -> humanizer_purchases (paket rows) | The anchor ledger reads only the caller's purchase rows |
| client -> sessionStorage | Dismissal flag is client-only state, no trust value |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-06-01 | Information disclosure | anchor purchase ledger | mitigate | listPaketPurchases runs under RLS select-own; the ledger shows only the signed-in user's own paket rows (dates/amounts), never another user's spend |
| T-07-06-02 | Tampering | sessionStorage dismissal flag | accept | Client-only UX state; tampering only re-shows or hides a non-blocking panel, no entitlement or data effect |
| T-07-06-03 | Spoofing (dark pattern) | fake scarcity/countdown | mitigate | Design + gate forbids countdowns and scarcity copy; verified by a negative grep and the honest delete-instead footer |
</threat_model>
