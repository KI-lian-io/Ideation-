<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user title input -> saveApplicationPackage | Free-text title crosses from the client into a stored row |
| result view -> save action | Explicit user action is the only write trigger (Datenschutz section 7) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-04-01 | Tampering | title free-text | mitigate | Title is rendered by React (auto-escaped) and stored as data, not HTML; no dangerouslySetInnerHTML on the title |
| T-07-04-02 | Repudiation | silent/auto save | mitigate | Save is invoked only from the explicit click handler; no autosave/blur-save path exists (verified by source review), honoring the explicit-save legal basis |
| T-07-04-03 | Information disclosure | confirmation panel content | accept | The panel shows only the user's own title/timestamp already in client state; no cross-user data |
</threat_model>
